# TripPlaner-AI--A-multi-Agent-Travel-Planner-With-LangGraph

A multi-agent AI travel planner built with LangGraph that autonomously searches flights and hotels, generates personalized itineraries, and maintains long-term travel context using PostgreSQL.

## How to run ?

1. Create the virtual Environment

```bash
conda create -n travel python=3.11 -y
```

2. Activate the Environment

```bash
conda activate travel
```

3. Install the requirements

```bash
pip install -r requirements.txt
```
